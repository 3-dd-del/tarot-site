# 塔罗牌网站 (tarot-site)

一个关于塔罗牌的主题网站。

## 当前状态

项目刚刚建立，尚未开始搭建。

产品方向与流程设计见 [docs/product-design.md](docs/product-design.md)。

## 规划中的方向

暂定 MVP 形态为 **「在线抽牌工具 + 牌义百科」**：

- 抽牌工具负责吸引用户与传播
- 牌义页面负责承接搜索流量
- 两者互相导流，同一套内容复用两次
