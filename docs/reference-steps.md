# 参考步骤

> 版本 v0.1 · 2026-10-01
> 用途：把塔罗牌网站跑起来，并在桌面留一个双击就能打开的入口。
> 相关文档：[技术方案](tech-solution.md)、[产品设计文档](product-design.md)。

---

## 0. 前提

仓库目前只有文档与牌面素材，**还没有网页代码**，所以第一步是先把站点建出来，之后才谈桌面入口。

---

## 1. 建站（Astro）

在仓库根目录执行：

```bash
npm create astro@latest .
npm install
npm run dev
```

跑完会得到一个本地地址，通常是 `http://localhost:4321`，浏览器打开就是网页。

---

## 2. 选择在哪里打开

先决定网页从哪里来，桌面入口才有东西可指向。

### 方式 A：部署到公网（推荐）

好处是手机、别的电脑都能打开，桌面快捷方式指向一个固定网址，不依赖本机有没有开服务。

1. 把代码推到 GitHub（已在做）
2. 去 Cloudflare Pages 或 Vercel 注册，关联这个仓库
3. 构建命令填 `npm run build`，输出目录填 `dist`
4. 得到形如 `https://tarot-site.pages.dev` 的网址

### 方式 B：只在本地跑

好处是不用部署，坏处是每次使用前都要先把服务启动起来。

---

## 3. 创建桌面快捷方式

### 3.1 最简单的一种（配合方式 A）

1. 桌面空白处右键 → 新建 → 快捷方式
2. 位置填网址，例如 `https://tarot-site.pages.dev`
3. 下一步，名称写「塔罗牌」，完成

双击即可打开，但它会开成一个普通浏览器标签页。

### 3.2 装成应用（体验最好）

在 Edge 或 Chrome 里打开该网址：

1. 地址栏右侧有「安装」图标；找不到就进菜单 → 应用 → 安装此站点为应用
2. 装完会自动在桌面与开始菜单生成图标
3. 打开时是独立窗口，没有地址栏，看起来与桌面软件一致
4. 可以右键固定到任务栏

这条路不需要手动新建快捷方式，图标也来自站点的 favicon，因此在项目里放一张图标文件即可。

### 3.3 本地启动脚本（配合方式 B）

桌面新建一个文本文件，改名为 `启动塔罗牌.bat`，内容：

```bat
@echo off
cd /d "C:\Users\w1550\Documents\ChatGPT\塔罗牌"
start "" http://localhost:4321
npm run dev
```

再给这个 bat 文件建一个快捷方式放到桌面，双击就会先开浏览器、再启动服务。缺点是关掉那个命令行窗口，服务就停了。

---

## 4. 换图标

Windows 快捷方式的图标必须是 `.ico` 格式：

1. 右键快捷方式 → 属性 → 更改图标 → 浏览，选中 `.ico` 文件
2. 没有 ico 文件的话，先用在线转换工具或 ImageMagick 把图片转成 ico

走「安装为应用」这条路时，图标取自站点的 favicon，无需手动更换。

---

## 5. 三种方式对比

| 方式 | 依赖本机服务 | 图标来源 | 适用场景 |
|---|---|---|---|
| 快捷方式指向网址 | 否 | 手动设置 | 已部署，想要一个桌面入口 |
| 安装为应用 | 否 | 站点 favicon | 已部署，想要接近桌面软件的体验 |
| 本地启动脚本 | 是 | 手动设置 | 还没部署，只想本机用 |

---

## 6. 最短路径

**建好 Astro 项目 → 部署到 Cloudflare Pages → 用 Edge / Chrome 的「安装此站点为应用」生成桌面图标。**
