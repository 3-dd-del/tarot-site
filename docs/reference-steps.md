# 参考步骤

> 版本 v0.2 · 2026-10-01
> 用途：把塔罗牌网站跑起来，并在桌面留一个双击就能打开的入口。
> 相关文档：[技术方案](tech-solution.md)、[产品设计文档](product-design.md)。

---

## 0. 前提

站点已经建好（Astro 静态站 + 一个抽牌岛），78 张牌面与牌数据都在仓库里。
所以现在只剩两件事：**跑起来**，然后**在桌面留一个入口**。

---

## 1. 建站与运行（Astro）

项目结构已经是 Astro 的标准结构，不需要再执行 `npm create astro@latest`。常用命令在仓库根目录执行：

```bash
pnpm install     # 安装依赖
pnpm dev         # 开发预览，通常跑在 http://localhost:4321
pnpm build       # 生成静态站点到 dist/
pnpm preview     # 预览构建产物
pnpm verify      # 构建 + 冒烟测试（路由、数据、脚本挂载）
```

抽牌流程需要 JS，其余页面在构建期就已经渲染成静态 HTML。

---

## 2. 选择在哪里打开

先决定网页从哪里来，桌面入口才有东西可指向。

### 方式 A：部署到公网（推荐，尚未执行）

好处是手机、别的电脑都能打开，桌面快捷方式指向一个固定网址，不依赖本机有没有开服务。

1. 把代码推到 GitHub（已在做）
2. 去 Cloudflare Pages 或 Vercel 注册，关联这个仓库
3. 构建命令填 `pnpm build`，输出目录填 `dist`
4. 得到形如 `https://tarot-site.pages.dev` 的网址

### 方式 B：只在本地跑（当前采用）

好处是不用部署、不依赖网络；坏处是每次使用前都要先把服务启动起来。
下面的第 3 节把这一步压缩成了一次双击。

---

## 3. 创建桌面快捷方式

### 3.1 一键脚本（当前采用）

先构建一次，再运行创建脚本：

```bash
pnpm build
powershell -ExecutionPolicy Bypass -File scripts\create-shortcut.ps1
```

会在桌面和开始菜单各生成一个「塔罗牌」图标，双击之后：

1. `启动塔罗牌.bat` 调起 `scripts/serve.ps1`
2. 脚本用 Windows 自带的 PowerShell 起一个本地静态服务（默认 4321 端口）
3. 自动打开浏览器指向 `http://localhost:4321/`

两个细节：**这条路径不需要安装 Node**，服务只用到 PowerShell；重复双击不会报端口占用，脚本检测到服务已经在跑就只打开浏览器。

关闭那个命令行窗口，本地服务就停了。

### 3.2 安装成应用（体验最好）

部署到公网之后（方式 A），在 Edge 或 Chrome 里打开该网址：

1. 地址栏右侧有「安装」图标；找不到就进菜单 → 应用 → 安装此站点为应用
2. 装完会自动在桌面与开始菜单生成图标
3. 打开时是独立窗口，没有地址栏，看起来与桌面软件一致

项目已经准备好 `public/site.webmanifest`、`public/sw.js` 与 192/512 图标，所以这条路径不需要额外改代码。

### 3.3 手动指向网址

桌面空白处右键 → 新建 → 快捷方式 → 位置填网址 → 名称写「塔罗牌」。
双击即可打开，但它会开成一个普通浏览器标签页。

---

## 4. 换图标

图标不依赖任何图像工具，由脚本直接生成：

```bash
node scripts/make-icon.mjs
```

会写出 `public/favicon.svg`、`public/favicon.ico`（16/32/48/64/128/256 六种尺寸）、`public/apple-touch-icon.png`、`public/icon-192.png`、`public/icon-512.png`，以及桌面快捷方式用的 `assets/tarot.ico`。

要换图标时改这个脚本里的图形函数即可；如果只想给现有快捷方式换一个 `.ico`，右键快捷方式 → 属性 → 更改图标 → 浏览。

---

## 5. 三种方式对比

| 方式 | 依赖本机服务 | 图标来源 | 适用场景 |
|---|---|---|---|
| 一键脚本 + 本地服务 | 是 | `assets/tarot.ico` | 已构建、只想在本机用（当前采用） |
| 安装为应用 | 否 | 站点 favicon | 已部署，想要接近桌面软件的体验 |
| 快捷方式指向网址 | 否 | 手动设置 | 已部署，只要一个桌面入口 |

---

## 6. 最短路径

**现在：`pnpm build` → 运行 `scripts\create-shortcut.ps1` → 双击桌面的「塔罗牌」。**

**以后部署完：用 Edge / Chrome 的「安装此站点为应用」生成桌面图标，本地的 `启动塔罗牌.bat` 就可以不用了。**
